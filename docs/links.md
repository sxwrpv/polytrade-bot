## Hostnames and safety

- `polytradebot.live` — canonical website, Help Center, and API hostname.
- `www.polytradebot.live` — public alternate hostname serving the same ingress.
- `t.me` — Telegram's public link hostname for `@cpolytrade_bot`.
- `github.com` — repository hostname.

This page intentionally omits IP-only ingress, backend ports, database endpoints, dashboards, SSH destinations, secret stores, and other private operational access. Do not publish them as official consumer or developer links.
